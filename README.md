Tablero de Corcho Virtual (Virtual Corkboard)
Una aplicación web moderna, interactiva y ligera diseñada para la gestión de notas, ideas y proyectos con una interfaz visual inspirada en un corcho tradicional. Está desarrollada completamente con Vanilla JavaScript (ES6+), HTML5 y CSS3, sin dependencias externas ni frameworks pesados, garantizando un rendimiento óptimo.

🚀 Características Principales
Sistema Multi-Tablero: Permite crear, alternar y gestionar múltiples tableros de notas de forma independiente.

Gestión Completa de Notas (CRUD): Creación, edición, marcado de completado y eliminación de notas.

Organización por Categorías y Subcategorías: Clasificación visual en Proyectos, Ideas, Tareas, Contenidos (con subcategorías específicas) y Otros.

Adjunto de Múltiples Imágenes: Soporte para seleccionar varias imágenes por nota, las cuales se procesan y almacenan de forma persistente en formato Base64.

Visor de Imágenes Interactivo (Galería): Al hacer clic en cualquier miniatura, se abre un modal flotante en pantalla completa que incluye controles de navegación (botones y soporte para las teclas de flecha izquierda y derecha del teclado).

Vista de Calendario Mensual: Visualización interactiva de las notas estructuradas según sus fechas de vencimiento.

Papelera de Reciclaje: Sistema de recuperación o eliminación permanente para las notas borradas.

Persistencia de Datos: Almacenamiento local automático mediante localStorage para conservar toda la información entre sesiones.

Modo Oscuro / Claro: Interfaz adaptable con detección automática de contraste para garantizar la legibilidad del texto en cualquier esquema de color.

Atajos de Teclado: Navegación ágil y creación rápida de notas mediante comandos de teclado (como la tecla N o Escape).

Copias de Seguridad (Backup): Funcionalidad para exportar e importar tus notas en formato JSON de forma segura.
